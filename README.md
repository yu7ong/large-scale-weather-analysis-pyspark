# large-scale-weather-analysis-pyspark

## Overview

This project explores large-scale historical weather data using Apache Spark.
The project covers data preparation, data integration, feature engineering, window function and machine learning using Spark ML.

## Dataset
The project uses the Global Daily Climate Data / Weather Dataset obtained from [Kaggle](https://www.kaggle.com/datasets/guillemservera/global-daily-climate-data/data). 
The dataset contains information about cities, countries and daily weather observations.

## Analysis
The notebook demonstrates:
- Data loading and preparation
- Joining multiple datasets
- Data cleaning
- Feature engineering
- Machine learning with Spark ML and model evaluation
